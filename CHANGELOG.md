# Release notes

## 0.4.0 - English and Chinese switching

- English default with a persistent English/Simplified Chinese desktop selector; switching preserves inputs and window size.
- `--language en|zh` for CLI help, messages, reports and review workbooks.
- Cross-language workbook imports and legacy Chinese workbook compatibility.
- Original source text, amounts, evidence, issue identities and arithmetic rules are preserved.
- 67 automated tests, including language selection, cross-language review, legacy files, tamper checks and source-text preservation.
- Portable Windows desktop build with bundled Python.

## 0.3.2 - public source release

- Local PDF field and line-item extraction with Decimal arithmetic checks.
- Excel discrepancy snapshots, editable review workbooks and hash-bound human corrections.
- English setup, privacy, pilot and validation guides, plus English synthetic demo PDFs.
- MIT license for original source and synthetic examples; separate dependency notices.
- 57 regression tests. No real-customer accuracy claim or prebuilt English Windows binary.

This release does not add accounts, cloud synchronization or automatic financial posting.
