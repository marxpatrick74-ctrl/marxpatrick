# Third-party components

Original SheetAudit source code and synthetic example documents are distributed under the root MIT license. Third-party components retain their own licenses. The project's MIT license does not relicense the bundled runtime or dependencies.

SheetAudit Desktop bundles a Python runtime and open-source dependencies. Their original licenses, copyright statements and notices remain applicable. The PyInstaller bootloader's distribution exception does not replace the licenses of bundled components.

Components include CPython / Tcl / Tk, PyInstaller bootloader, pdfplumber, pdfminer.six, openpyxl, et_xmlfile, pypdfium2 and PDFium, Pillow, cryptography, cffi, charset-normalizer and pycparser. A generated `THIRD_PARTY_LICENSES` directory and the bundled `_internal` directory contain notices from the actual build environment. The build manifest records installed versions.

The PDF files shipped as examples are synthetic demonstration data created for this project. No real customer documents, customer identity information or financial records are included.
